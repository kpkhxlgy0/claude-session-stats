# Claude Session Stats v0.2.0

新增 Claude Desktop Remote Control 统计：turns、steps、估算 TPS、累计 Token 和 Cache hit。
保留输入框下方的居中布局，不显示上下文占用。

- 只修改 tweak，使用接收端已有登录态读取原始同步事件，无需远端安装、OpenTelemetry 或代理服务。
- 仅统计明确标记为 bridge 的 Remote Control 会话；按响应 ID 去重流事件和最终快照。
- 历史分页在后台加载，随后按游标增量更新。加载未完成或数据缺失时显示 `—`；TPS 使用原始时间戳并标记为估算值。
- 修复深层页面组织绑定和慢速历史请求导致底栏不显示的问题。
- 会话/组织切换和停用时清理旧读取；继续支持本地统计、热加载和 Inject/Uninject 脚本。

已通过 122 项自动化测试，并在真实 Remote Control 会话确认完整历史、完整 usage 和可用估算 TPS。
需要 Claude++ 0.3.6 或更新版本；新增 network 权限用于只读访问 Claude 的会话接口。

统计范围仅包含 Remote Control 已同步的主会话历史，不能补齐远端未同步的旧日志。
