# Session Stats v0.6.2 — Subagent display stability

修复长对话中子代理统计栏消失后无法恢复的问题，并改善主会话和当前选中子代理的统计刷新。

- 身份识别跳过已确认的消息正文子树，保留会话、选中任务和子代理的关联校验；正确处理 React 复用的 current/alternate 节点。
- 主会话、后台子代理和前台目标分开调度，切换目标不再等待旧目标或同批兄弟发布完毕。子代理最多每批读取 8 个，缓存上限提高到 256 个，并限制闲置缓存缓冲区总量。
- 合并尚未开始的重复身份校验；批次完成后仍全量检查元数据唯一性，只重新解析本批相关工作目录。保留真实采样时间、30 秒有效期和共享快照一致性校验。
- 保留 v0.6.1 的 24px 子代理底部预留空间，以及 Windows 测试路径修复。

已知限制：大量未选中子代理的后台快照仍可能超过有效期。远程需求通知的数据通道已完成可行性验证，本版本尚未接入该通知机制，也不宣称所有远端子代理始终保持新鲜。

最低 Claude++ 核心版本仍为 0.3.6；快照格式及权限不变。建议运行端与接收端均更新到本版本。

验证：合并结果通过 466 项自动化测试、构建/清单校验和独立代码审查。真实会话验证了长正文下的子代理绑定恢复，以及本地统计与对应共享快照数值一致；完整记录见 `docs/superpowers/validation/2026-10-28-background-subagent-scheduling.md`。
