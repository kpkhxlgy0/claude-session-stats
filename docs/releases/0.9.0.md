# Session Stats v0.9.0 — Desktop Remote Control metadata synchronization

修复 Desktop 本地 Code 作为运行端时，Remote Control 统计请求无法到达旧处理器的问题。运行端现在把已验证的
主会话和子代理数值快照发布到 Claude 会话元数据，接收端使用原生会话 API 读取；不修改 CLI。

- 配置目录和日志路径只由运行端解析，继续跟随 `CLAUDE_CONFIG_DIR`。接收端不猜测远程目录。
- 复用已有累计统计和 TPS 样本，不重新累计用量；主会话与子代理独立显示，缺少有效 TPS 时仍显示 `—`。
- 发布使用账户/组织约束及条件更新，防止并发覆盖其他发布者；只修改本 Tweak 的元数据字段。
- 保留身份、版本、大小及 30 秒时效校验。轮转、取消、停用、重启和本地样本失效均有回归覆盖。
- 单会话最多每 10 秒发布一次，网络失败不影响本地统计。热重载产生的新发布者通常需等待旧快照过期后接管。
- 删除接收端旧控制请求与事件轮询；不再依赖 Claude++ 的 `session-stats` 核心接口。

**运行端和接收端都需更新 Session Stats 至 0.9.0，最低 Claude++ 仍为 0.3.9。** 仅更新 Tweak 可以热加载。
配套 Claude++ 0.3.10 移除旧核心注入；更新核心时需要完全退出并重启 Claude。

验证：全部 675 项 Tweak 测试、构建和清单校验通过，独立审查通过。真实服务验证了条件更新与并发冲突保护；
本机四个运行会话的云端快照与本地数值一致，其中一个包含 52 个子代理。指定异机运行端仍需更新后进行最终显示验收。
