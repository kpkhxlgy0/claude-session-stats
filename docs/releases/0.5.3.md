# Session Stats v0.5.3 — Restore statistics after worktree moves

修复会话进入工作树、返回项目根目录或重启 Desktop 后，统计栏持续显示 `—` 的问题。

- 当前工作目录与 Desktop 根目录相同时，也为完整的 CLI 会话登记生成可重新验证的身份证明，恢复迁移日志的选择。
- 兼容不再提供桥接 ID 的 CLI 登记；继续通过唯一的 Desktop 桥接映射、精确的本地/CLI 会话 ID、唯一活动进程及启动标识核验身份。明确冲突的字段仍会拒绝。
- 对逐字节完全相同的等长日志副本确定性地选择一份；对完整前缀副本选择最长的已验证历史，统计不重复累加。
- 返回原项目后，重新确认历史迁移目录与原项目或已登记 Git 工作树的关联。历史网络共享与设备路径不会触发目录探测，每次扫描最多核验四个不同历史目录。
- 保留读取前后身份、文件版本与目录校验；内容分叉、不完整日志、无效关联或超出限制时继续显示不可用。

验证：347 项自动化测试通过，清单、renderer bundle 和安装入口校验通过。两个真实本地工作树会话恢复有效统计；各三次只读采样均与运行端发布的快照逐项一致。临时诊断代码已移除。异机 Remote Control 界面未在本次操作中重复验收。

快照格式、统计口径、权限和依赖保持不变，最低 Claude++ 版本仍为 0.3.6。请升级实际运行会话的机器上的 Session Stats；只更新接收端不能修复运行端的日志选择问题。商店条目固定到本次发布的完整提交 SHA。
