# Session Stats v0.10.1 — 自动配置远程快照目录权限

修复 Remote Control 因缺少快照目录权限而一直显示 `—` 的问题。运行端现在自动通过 Desktop 原生接口，将自己的 `.session-stats` 目录加入相应会话，无需逐个输入 `/add-dir` 或发送文件夹附件。

- 已有的有效 RC 会话自动补齐；新会话获得 RC 绑定后自动处理。
- 仅添加统计快照目录，保留其他权限，不写项目目录或全局权限配置。
- 原生接口暂不可用时有限重试；兼容多个窗口和历史 RC 绑定，取消或过期请求不再延后授权。
- 已授权会话跳过重复的磁盘和 Git 权限核验。TPS、累计用量和显示布局保持原有口径。

运行端需更新到 **Session Stats 0.10.1**，接收端的 0.10.0 目录读取协议仍兼容。最低 Claude++ 版本仍为 0.3.9，本次无需更新核心或 CLI。Tweak 支持热加载；发布者交接可能需要等待旧元数据过期，通常约 30 秒。

验证：726 项测试、构建和清单校验通过。本机 26 个有效旧会话已补齐授权，活动 CLI 未重启；真实 RC 读取返回的快照与本地统计完全一致。另一台电脑的显示界面未直接检查。
