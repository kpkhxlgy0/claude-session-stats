# Session Stats v0.5.0 — Fork inherited history TPS

Fork 后的跨轮平均 TPS 现在包含实际继承的历史，再与分支的新响应一起累计。本地统计条和 Remote Control 接收端继续使用运行端生成的同一份快照。

- 支持 Desktop 原样复制的历史和带 `forkedFrom` 的副本；按可验证的父子关系、复制前缀和原始时间计时。
- 多层 fork 逐层追溯并去重，不计入父会话在 fork 后新增的响应，也不把创建分支后的等待时间当作生成耗时。
- 来源缺失、关系冲突、文件持续变化或超过读取上限时，TPS 显示 `—`；其他可独立确认的指标继续显示。
- Turns、Steps、Token 和 Cache hit 保留原有统计范围。TPS 仍标记为估算值，包含首 Token 等待和网络耗时。
- RC 接收端仍只读小型统计快照，不新增权限、依赖或后台服务。

使用此功能需要将运行端更新到 v0.5.0，建议接收端同时更新。快照协议兼容 v0.4.1 及以后版本；Claude++ 最低版本仍为 0.3.6。

验证：255 项自动化测试、构建与安装入口校验；两个真实原生 fork 的继承值核对；真实跨机器 RC 读取中，同一快照版本的 13 个统计与版本字段完全一致，TPS 均为 71.98419541222047，读取耗时约 1.36 秒。
