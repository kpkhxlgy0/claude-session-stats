# Session Stats v0.5.1 — Worktree synchronization and stable local display

修复会话进入工作树后统计无法显示，以及本地统计数字反复变成 `—` 的问题。

- 快照发布位置跟随已确认的 CLI 当前工作目录；接收端通过 RC 读取同一目录下的固定相对路径，保留原有权限和身份检查。
- 工作树迁移留下同 UUID 日志副本时，只在所有副本构成可验证的完整字节前缀、且迁移标记与活动工作目录一致时读取唯一最长的一份。不叠加重复历史，也不按修改时间猜测来源。
- 本地界面读取已发布样本，不再等待所有会话完成后台统计，避免超过 Claude++ 的 5 秒 IPC 超时。
- 修复心跳替换及文件已写出、发布状态尚未提交时的并发读取，正常更新不再使统计短暂失效。
- 继续核对工作树、进程启动标识、会话身份、文件版本和有效期；缺失、冲突或失效的数据仍显示不可用。启动或热重载后，首份有效快照生成前仍需等待。

**运行端和接收端都需更新到 v0.5.1，才能使用这次工作树目录同步修复。** 快照数据格式、统计口径和权限保持不变；TPS 仍为跨轮累计的估算值。Claude++ 最低版本仍为 0.3.6。

验证：317 项自动化测试、构建与安装入口校验。真实本机会话在首份有效样本出现后连续观察 86 秒，37 次读取全部成功，43 次前台采样跨越 7 个快照版本未再闪断；正常读取平均约 1.9 秒。真实双端同版本快照的统计数值一致。
