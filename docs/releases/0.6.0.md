# Session Stats v0.6.0 — Selected subagent statistics

打开 Claude Code 的子代理详情时，在面板底部居中显示该子代理自己的 turns、steps、估算 TPS、累计 Token 和缓存命中率。

- 统计条距底边 2px，采用绝对定位，不占布局高度、不增加留白、不挤压正文或输入框；不显示上下文占用。
- 切换子代理时按所属会话与子代理 ID 重新绑定，丢弃旧请求结果；返回列表、隐藏或关闭面板时清理。
- 读取对应子代理日志，按消息和请求 ID 去重，不混入父会话、兄弟子代理或继承的父会话用量。TPS 沿用有效响应样本口径，缺少有效样本时显示 `—`。
- Remote Control 使用单独的子代理统计快照，严格校验会话、组织、子代理、版本和有效期，不下载远程原始日志。
- 主会话继续使用原有 v1 快照；子代理使用独立 v2 快照。带输入框的子代理面板不会影响主会话和子代理的远程读取。

**远程子代理统计需要运行端与接收端都更新到 v0.6.0 或更高版本。** 最低 Claude++ 核心版本仍为 0.3.6，无需新增权限或依赖。

验证：414 项自动化测试通过，构建与清单/安装入口校验通过，独立代码审查无剩余实质问题。真实子代理日志重复读取结果一致；用户已确认界面显示数值。最终布局由 DOM/CSS 测试和用户确认验收，未宣称完成自动化截图比对。
