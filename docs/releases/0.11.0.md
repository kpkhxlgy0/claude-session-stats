# Session Stats v0.11.0 — 按需统计

仅为当前打开的会话和选中的子代理计算统计，切换、隐藏或关闭视图后撤销对应需求。没有可见目标时，不再遍历历史会话和子代理日志，也不生成统计快照。

- 多窗口需求相互独立，过期或取消的任务不能发布迟到结果。
- Remote Control 使用独立的短租约传递可见目标；慢请求期间续租，离开后撤销，断线后自动过期。运行端仅为已验证的活动 CLI 保留轻量需求检查。
- 冷启动无需预先计算快照；首次文件尚未生成时会短暂重试。
- 保留工作树、fork 继承历史、绑定核验与损坏快照恢复规则；改进缓存及部分文件读取，避免重复统计无关目标。

完整远程按需行为要求运行端和接收端均升级到 **0.11.0**。最低 Claude++ 版本仍为 0.3.9，无需升级核心。

验证：716 项自动化测试、构建和清单校验通过。真实本地会话及选中子代理已验证，切走后停止读取原目标。接收端真实元数据接口已验证。

**验收限制：** 本次完整真实 Remote Control 自动链路和最终界面显示尚未验收通过，测试机当前 Claude 进程存在独立于统计请求的 Chromium 网络故障。本版本未包含该连接超时问题的修复。
