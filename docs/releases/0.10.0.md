# Session Stats v0.10.0 — 按需读取 Remote Control 统计

Remote Control 改为通过 `client_metadata` 发布运行端真实快照目录，再用原生 `read_file` 读取当前查看的
主会话或子代理快照。修复 v0.9.0 把全部子代理打包上传、整批请求失败时连主会话统计也停止更新的问题。

- 快照目录跟随运行端实际 `CLAUDE_CONFIG_DIR`；未设置时使用 `~/.claude/.session-stats`，接收端不猜用户目录。
- 元数据只包含目录和归属信息，大小不随子代理数量增长。未打开的子代理不通过远程读取传输。
- 主会话与子代理分别请求，保留原有 TPS、累计用量和去重口径；重复刷新不重复计数。
- 保留身份、路径、大小、有效期、版本和取消校验。读取期间目录或发布者变化会丢弃旧结果。
- 旧版数值摘要在过期后条件替换为目录描述，不覆盖其他元数据字段或新鲜的其他发布者。

**运行端和接收端都需更新 Session Stats 至 0.10.0，最低 Claude++ 仍为 0.3.9。** 本次无需更新核心或 CLI。
Tweak 支持热加载；发布者交接可能等待旧描述过期，通常约 30 秒。v0.9.0 无法读取新的目录协议。

验证：691 项自动化测试、构建、清单和安装入口校验通过，独立审查无实质问题。
覆盖自定义目录、65 个子代理、主/子独立读取、续接分叉、重复刷新和发布者交接。
按用户要求复用已有 `read_file` 能力，未重新进行远端能力探测；自动化结果不代表新的异机实测。
