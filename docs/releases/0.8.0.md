# Session Stats v0.8.0 — Claude configuration root and stats RPC

Remote Control 改用 Claude++ 核心提供的专用统计接口，读取运行端已发布的同一份主会话或子代理快照，不重新计算用量。

- 快照写入 `<CLAUDE_CONFIG_DIR>/.session-stats`；未设置时使用 `~/.claude/.session-stats`。旧目录与损坏快照备份保留原位。
- 统计 provider 只返回身份唯一、仍然有效的已发布快照。请求取消、会话切换、停用或连接关闭后，旧结果不能继续显示。
- 接收端使用 `claudepp_session_stats` 协议 1，继续校验会话、组织、子代理、数值、大小、版本顺序和有效期，不再请求读取远端文件。
- 新增 `session-stats` 权限，最低 Claude++ 核心版本提高到 0.3.9。统计口径及主会话/子代理快照格式保持不变。

**运行端和接收端均需 Claude++ 0.3.9 与 Session Stats 0.8.0 或更新版本。** 升级时先完全退出 Claude，安装或更新
Claude++ 核心，再安装或更新 Session Stats 并重新启动 Claude；仅热加载 tweak 不能加载新的核心适配。
当前核心适配支持运行端 Claude Desktop `4.23118.0` 的原生 Remote Control 连接。独立终端 CLI 启动、没有 Claude++
Desktop 桥接的会话不在支持范围内；不支持的运行端不会回退到文件读取或猜测目录。

验证：构建、清单校验和全部 616 项自动化测试通过。本机已安装并重启 core 0.3.9 与 tweak 0.8.0，实际配置根目录下
观察到 101 份新鲜快照。异机端尚待更新，跨机器 Remote Control 最终显示仍未验证。
