# Claude Session Stats v0.3.0

TPS 改为跨多轮累计的会话平均值，适用于本地 Claude Code 和 Desktop Remote Control 会话。

- 对有效响应的输出 Token 和对应耗时分别求和，再相除；不直接平均每次响应的 TPS。
- 新消息、工具执行和后续生成期间保留已有平均值，首个有效样本出现前显示 `—`。
- Remote Control 生成中的响应暂不计入平均值，完成后再更新；处理未完成流、重连重放、requestId 别名和迟到事件，避免半截响应或旧流污染统计。
- 保留 `≈` 标记，并在提示中说明统计范围和计时口径。耗时仍包含首 Token 等待、思考和网络时间，不代表服务端纯生成速度。

统计范围仍为当前可验证的本地会话历史或 Remote Control 已同步的主会话历史；不补齐远端未同步的旧日志。
需要 Claude++ 0.3.6 或更新版本，无新增依赖或权限。

验证：165 项自动化测试、构建、安装入口与版本一致性校验通过；真实本地日志回放确认其他统计指标保持不变。
