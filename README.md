# Session Stats for Claude++

在 Claude Desktop 的本地 Code 和 Remote Control 会话输入框下方显示：

```text
24 turns · 412 steps · ≈ 42 tok/s    176.7M tok · Cache hit 99%
```

五项统计在输入区底部居中独占一行，优先利用窗口已有的底部留白。

打开子代理详情后，在该面板底部预留 18px；统计行高 14px，居中显示，上下各留 2px。
正文滚动区域相应缩短，避免与统计重叠；切换子代理、返回任务列表或关闭面板时同步切换或移除并恢复原有布局。
主会话与子代理分别计算，子代理日志不会被叠加到主会话。子代理缺少有效 TPS 样本时显示 `—`。
子代理沿用下述有效样本口径：缺失用量或计时的响应不进入 TPS 的分子和分母，不用它们推算速度。

## 安装和卸载

需要 Windows 和已安装的 Claude++ 0.3.9 或更新版本。
在 Claude++ 的 Tweak Store 中搜索 **Session Stats** 并安装。Store 固定到审核过的完整提交 SHA。

源码：[kpkhxlgy0/claude-session-stats](https://github.com/kpkhxlgy0/claude-session-stats)。
当前版本：[v0.11.0](https://github.com/kpkhxlgy0/claude-session-stats/releases/tag/v0.11.0)。

自 v0.11.0 起，仅计算当前可见主会话与选中的子代理；切走、隐藏或关闭面板后释放需求，停止后续日志读取和统计刷新。
Remote Control 使用独立 viewer 的八秒短租约请求精确目标，**运行端和接收端都需升级到 Session Stats 0.11.0 或更新版本**。

自 v0.8.0 起，快照保存在运行端的 `<CLAUDE_CONFIG_DIR>/.session-stats`，未设置时为 `~/.claude/.session-stats`。
Remote Control 通过会话元数据发现运行端真实快照目录，再用原生 `read_file` 按需读取当前主会话或子代理。两端均需 Claude++ 0.3.9 或更新版本及 Session Stats 0.11.0 或更新版本。
自 v0.10.1 起，运行端会自动通过 Desktop 的原生目录接口，把自己的 `.session-stats` 目录加入对应本地会话的附加目录权限。
已有的有效 Remote Control 会话会补齐，新会话获得 RC 绑定后自动处理，无需输入 `/add-dir` 或发送附件。
仅授权统计目录，不改项目文件或全局权限；会话身份、目录或原生接口无法确认时等待重试。
目录授权由 Desktop 保存在会话中，启用中的 CLI 由 Desktop 异步同步；接口接受授权不等于已确认远端读取成功。
仅更新 Session Stats 支持热加载。Claude++ 0.3.10 清理了旧核心适配，推荐一并更新；更新核心时需完全退出并重新启动 Claude。

也可以使用 PowerShell 7 运行仓库根目录的脚本：

```powershell
pwsh -NoProfile -File .\Inject-ClaudePlusPlus.ps1
```

只检查当前状态、不修改文件和配置：

```powershell
pwsh -NoProfile -File .\Inject-ClaudePlusPlus.ps1 -CheckOnly
pwsh -NoProfile -File .\Uninject-ClaudePlusPlus.ps1 -CheckOnly
```

卸载：

```powershell
pwsh -NoProfile -File .\Uninject-ClaudePlusPlus.ps1
```

Inject 在 `%APPDATA%\claude-plusplus\tweaks\com.kpk.session-stats` 建立指向本目录的 junction 并启用此 tweak。
Uninject 禁用此 tweak，只移除指向本目录的 junction，保留源码；已经存在的 Store 实体安装只启用或禁用，不覆盖或删除。
指向其他源码的链接及无关目录会阻止操作。其他 tweak 设置和 safeMode 保持原值；safeMode 开启时，本 tweak 不会加载。
Claude++ 已运行时，tweak 源码和构建产物更新会自动热加载。核心统计通道的首次安装或升级需要重启 Claude。
脚本不会自动退出或重启 Claude。

`index.js` 已包含可直接加载的 renderer 代码，安装无需下载开发依赖。

## 统计口径

| 字段 | 含义 |
| --- | --- |
| Turns | 当前主会话的用户输入轮次，按 promptId 去重，旧记录退回 uuid；不计工具返回、系统注入和子代理分支 |
| Steps | 当前主会话的模型响应次数，按 message.id / requestId 去重；同一响应的重复记录和累计快照不会重复累加 |
| Token | 累计普通输入 + 缓存写入 + 缓存读取 + 输出 |
| Cache hit | 累计缓存读取 ÷ 累计总输入；缺字段或分母为零时显示 `—` |
| TPS | 包括 fork 继承历史的有效响应输出 tokens 总和 ÷ 对应响应耗时总和；跨用户轮次累计，以 `≈` 标记估算值 |

Token 采用运行端原始会话日志提供的用量，不按可见文本长度估算。Remote Control 读取运行端已经算好的统计快照。
模型代理或转发服务若缺失 usage 字段，相应指标显示 `—`。
累计 Token 是各次模型请求的总用量，重复读取的缓存也会累计，因此可能远大于单次上下文窗口。

TPS 使用运行端现有日志时间戳，无需 OpenTelemetry、代理或额外采集服务。
每个响应按消息 ID / requestId 去重，耗时从对应用户输入或工具返回计至该响应记录；多条内容块取同一响应的最晚日志时间。
先汇总有效响应的输出用量和耗时，再相除；不直接平均各次 TPS，也不把整段会话等待时间作为分母。
例如两次响应分别输出 1000 tokens、耗时 5 秒和 20 秒，会话平均为 `2000 / 25 = 80 tok/s`。
分母包含请求等待、思考和网络耗时；工具返回后为下一次响应重新计时，工具返回之前的执行间隔不计入该次响应。
新用户消息、工具结果和后续生成不清空已有会话平均值；首个有效样本到来前显示 `—`。
缺少起止时间或输出用量、时间倒序或不足 100ms 的响应不进入 TPS 的分子或分母；有效的零输出响应仍计入耗时。
TPS 因此只代表当前可验证的有效响应样本；该值包含首 Token 等待，不等同于排除了首 Token 等待的纯生成速度。
续接或重连重放同一 `promptId` 时，即使记录 UUID 改变，也不重新开始 TPS 计时，
真正的新输入和工具返回仍分别开始新的计时间隔。
工具返回优先按 `tool_use_id` 去重，缺失时使用记录 UUID；两者都缺失时不推算该次响应的 TPS。

Fork 的 TPS 会继承实际复制的历史，再与分支之后的新响应一起累计，不把父会话后来新增的响应计入。
Desktop fork 使用会话元数据中的父子关系，核对副本与源日志的消息、顺序和时间；
带有 `forkedFrom` 的 SDK/CLI 副本则追溯原记录，使用原始时间，避免把 fork 时刻误算为响应结束时间。
多层 fork 继续追溯并去重；分支创建后的等待不计入历史响应耗时。
这只扩大 TPS 的继承范围，Turns、Steps、Token 和 Cache hit 仍沿用原有会话范围。
无法验证来源、边界或文件版本时 TPS 显示 `—`，不冒充完整累计值；独立可验证的其他指标继续显示。
接收端仍只读取运行端的同一份统计快照，不另读父会话日志，也不重新估算 TPS。

## 数据和会话范围

- 本地 Code 支持 `app://localhost` 和 `https://claude.ai` 下的 `/code/local_<uuid>` 与 `/epitaxy/local_<uuid>`。
- 主进程使用 Claude 的 userData 目录，读取 `claude-code-sessions/<账户>/<组织>/<local_id>.json` 中的精确映射；兼容没有组织层的布局。
- 检查记录的 sessionId 与请求一致，cliSessionId 有效，且不存在其他账户中的同名记录。缺失或歧义时显示 `—`。
- 增量读取 `$env:CLAUDE_CONFIG_DIR\projects\<项目>\<cliSessionId>.jsonl`；环境变量未设置时使用用户目录下的 `.claude`。
- 日志索引最长缓存 15 秒，新日志可能需要等待下一次索引刷新。文件追加、截断、替换会重新计算或增量更新。
- 工作树迁移若留下同 UUID 的日志副本，先核对 Desktop 会话绑定、工作目录和迁移标记，有活动 CLI 登记时再核验进程身份。所有副本都逐字节构成同一份完整历史的前缀时，
  读取最长的一份；完全相同的等长副本按固定路径顺序选取一份，不叠加。历史工作树已删除时，可用 Desktop 记录的最后一条助手消息 UUID 核对最长副本的消息末端。若较短的不同副本也有同一末端，则保留歧义。
  历史网络共享和设备路径不触发目录探测，每次日志扫描最多核验四个不同的历史目录。
  目录名或修改时间不作为选源依据；历史分叉、证明缺失和超出读取或核验上限时仍不显示统计。
- 本地迁移日志有匹配当前会话的 `relocated` 标记、且当前记录通过完整 `parentUuid` 链连接到已复制历史时，
  将同一文件内的这些旧会话记录纳入统计，继续按模型响应 ID 去重，不另外读取源日志叠加。
  无关记录和子代理分支不计入；父链缺失、循环、身份冲突或消息顺序不明确时显示 `—`。
  父链索引仅保存标识和关系，最多 65,536 条；超过限制的迁移历史不显示部分累计值。
- 有 RC 绑定的本地会话将快照写入运行端的 Claude 配置目录。原始日志和 Claude 权限设置均保持只读。
  IPC 只返回数值统计与关联标识，不传输会话正文。
- 子代理通过当前详情面板的 `agentId` 和所属会话定位，只读取对应的
  `<cliSessionId>/subagents/agent-<agentId>.jsonl`。用户/模型记录须同时匹配父会话、子代理和 sidechain 身份；
  重复响应按消息 ID/requestId 合并，不重新累计，不继承父会话用量或 TPS。路径、身份或完整性无法确认时显示 `—`。
  子代理日志按 64 KiB 块增量读取，单条记录最多 8 MiB，最多缓存 256 个子代理统计；每个父会话最多发现 128 个子代理。
  同一父会话每批最多读取 8 个子代理，共享批内父源定位，并在批次前后重新验证父身份、目录和文件版本；每份子代理日志仍单独校验。
  已解析的正文不进入缓存，闲置缓存保留的未完成行与首尾校验片段受 16 MiB 总预算约束。
  面板身份识别跳过已确认的消息气泡正文子树，长消息不会耗尽控制节点的扫描预算；仍核对当前会话、选中任务和子代理身份，拒绝冲突绑定。
  续接子代理后，仍可查看同一子代理先前调用的统计；核对详情面板选中的调用与明确的任务 ID，不因任务记录更新到新的续接调用而隐藏统计。
- 普通 Chat、Cowork、云端 Code、SSH 不在本版本范围内。

### Remote Control

- 支持 `/epitaxy/session_<id>`，兼容 `/code/session_<id>`。必须确认当前组织、未共享的 `bridge` 会话和已连接的运行端。
- 运行端从 Desktop 账户/组织目录中的精确映射取得原始 CLI 日志；按 `bridgeSessionIds` 为每个 RC 绑定生成
  `<CLAUDE_CONFIG_DIR>/.session-stats/session_<id>.json`。未设置 `CLAUDE_CONFIG_DIR` 时使用 `~/.claude/.session-stats`。
  日志与快照使用同一个配置根目录。旧版用户目录和项目内的快照及备份保留原位，不混入新目录的统计。
  快照只包含统计数值、会话/组织标识、发布者标识、递增版本和更新时间，不包含正文、原始日志路径或认证信息。
- 子代理使用同目录的 `session_<id>.agent-<agentId>.json` 独立快照，并验证所属会话、组织和子代理 ID。
  主会话使用 v1 快照，子代理使用 v2 快照。**两端均需 Claude++ 0.3.9 或更新版本及 Session Stats 0.11.0 或更新版本；旧版不支持新的按需租约协议**。
- **严格按需计算**：只为当前可见的主会话和选中的子代理计算统计。没有界面兴趣时，不索引/读取日志、不枚举子代理、不计算历史会话、不写统计快照。
  运行端保留有界内容缓存和活动日志增量游标；请求需要的 fork 祖先和重复日志来源仍会按规则核验。
  界面实例持有独立的八秒租约，定期续租；切换会话、隐藏、关闭子代理面板或停用会立即释放。多个窗口不会相互取消。
  已启动任务带有目标代次，释放后即使 I/O 迟到也不能发布旧样本。
  只有仍被请求的精确目标每 2 秒刷新；数值变化时原子替换，未变化时每 10 秒更新心跳，样本有效期仍为 30 秒。
  同一目标写入保持串行。磁盘 I/O 失败时仅显示通过身份与有效期校验的同次本机样本，并标为「仅本机」。
  会话进入或退出工作树时重新核对日志来源，快照路径固定在 Claude 配置目录。移动到原项目之外时还需核对 Git 共同目录和工作树登记。
- Git 工作树关联和进程查询最多复用 2 秒。工作目录、会话登记与目录身份继续实时检查；Git 控制文件及工作树登记变化会触发原生重查，无法安全确认缓存时也重新查询。
  缓存命中不会延长有效期；登记文件未反映的进程退出/复用，以及未纳入控制指纹的外部 Git 配置变化，最迟在该短窗口到期后重新确认。
  Desktop 仅更新标题、活动信息或计数时，重新读取稳定元数据并确认绑定语义未变，不再仅因文件版本变化而清掉统计。
- Remote Control 同样按需：接收界面先通过当前会话的 `client_metadata_patch` 写入独立 viewer 需求键，再请求原生 `read_file`。
  `claudepp_session_stats_request_<viewer>` 仅包含版本、会话/组织、租约代次、过期时间和可选子代理 ID；不发送聊天消息或执行提示词。
  每个窗口独立生成 viewer 身份，主会话/子代理使用独立键，八秒到期；切走通过 `test` + `remove` 只撤销自己的旧租约，迟到清理不能删除新目标。
- 运行端的控制面只查询本机仍存活、进程出生时间匹配的 CLI 注册会话，读取这些 connected RC 会话的需求。注册索引在启动/目录变更时更新。
  没有需求时不计算统计。活动桥的 `claudepp_session_stats` 目录描述独立于统计快照发布，冷请求无需等待一个预先计算的样本。
  描述仍使用 v2 目录协议、账户/组织约束与比较交换；另一发布者的新鲜描述及未知格式不会被抢写。
- 接收端只请求当前主会话或选中子代理的精确文件，不批量读取子代理。接收值替换显示，不重复累加。
  页面隐藏、导航、子代理关闭和停用会中止等待并撤销需求；断网时短租约自然过期。两端都需要此按需实现。
  主进程的认证请求与原生文件能力必须正常；传输未验证时不能把单元测试或本机缓存当作远程成功。
- 快照最多 16 KiB；校验会话、组织、发布者、版本顺序和数值。超过 30 秒未更新或来自未来超过 5 秒的数据不可用。
  两台设备的系统时间应保持同步。缺失、拒读、截断、离线和过期时显示 `—` 及原因，不回退到同步事件估算 TPS。
- 运行端确认当前会话/子代理绑定并取得有效统计后，遇到空文件、全零或 JSON 无法解析的快照，会先将原始字节备份到
  `<CLAUDE_CONFIG_DIR>/.session-stats/corrupt-backups/`，再原子重建。同一文件的相同损坏内容复用已有备份，备份不会随停用清理。
  JSON 可解析但归属冲突或格式未知的文件，以及链接、过大或读取时发生变化的文件，仍不会被当作可恢复快照覆盖。
  备份或磁盘写入失败时保留原文件，等待下一次成功刷新；自动恢复不能代替磁盘故障修复。
- 会话/组织切换、停用和身份变化会取消旧读取。运行端只清理自己生成的快照与临时写入文件，保留无关文件。
  停用后的残留快照会按原来的采样时间过期。

## 界面兼容与验证范围

渲染器按当前页面唯一可见的编辑器及相邻操作按钮识别输入框。本地统计不依赖 React 私有数据；
Remote Control 的组织绑定读取 React Context，Claude 前端更新可能需要同步适配。
主会话统计在权限和模型按钮下方独占居中的 14px 行。贴近窗口底部时优先利用已有底部留白，只为剩余行高腾出空间。打开或收起右侧面板时，统计行随对话列调整宽度。
切换会话后拒绝旧请求的返回结果。
同一会话发送提示词导致输入框短暂重建时复用原统计条，避免先清空再显示；跨会话或身份失效时仍清除。
若发现多个可见编辑器、未知页面或隐藏输入框，则不挂载统计条。停用时移除 DOM、监听和定时器。

已用本机 Claude Desktop 3.1623.0.0 的三个真实会话验证文件映射和完整用量解析。
自动化界面测试使用模拟 DOM；真实 Claude 界面的输入框识别、底部留白和最终显示位置仍需安装后验收。
RC 快照协议覆盖真实文件写入与接收解析的集成验证，另有身份、过期、截断、断线和并发回归测试。
新版本必须同时安装到运行端和接收端后，才能验证指定异机会话的最终显示；本机测试不能代替该步骤。
v0.11.0 已使用本机真实日志验证主会话、选中子代理、目标切换和需求释放后零新增日志读取。
本次真实远程自动端到端验收尚未完成：当前本机 Claude 进程的 Chromium 网络请求失败，loopback 请求也受影响。
此发布不表示该连接问题已修复，自动化测试和本机结果不能代替异机验收。

## 开发

```powershell
npm ci
npm run build
npm test
npm run validate
```

修改 `src/renderer.cjs` 后运行 build 更新 `index.js`。Claude++ 的 renderer 环境没有 Node require，发布入口因此内嵌 renderer；main 仍加载 `src/main.cjs`。
`src/session-map.cjs` 负责 Desktop 到日志的映射，`src/session-store.cjs` 负责只读增量加载，`src/metrics.cjs` 负责统计。
`src/session-history.cjs` 负责核对本地迁移日志的父子关系，确认可以计入的已复制历史。
`src/session-source.cjs` 校验同 UUID 迁移副本的完整前缀关系，以及工作目录或 Desktop 消息末端的来源证明。
`src/fork-metadata.cjs` 核对 Desktop fork 的父子映射，`src/fork-history.cjs` 有界读取和验证继承来源，只扩展 TPS 样本。
`src/snapshot.cjs` 定义两端共用的快照协议；`src/snapshot-bindings.cjs` 和 `src/snapshot-publisher.cjs` 负责精确目标映射、租约和按需发布。
`src/cli-workspace.cjs` 核对 CLI 活动会话与工作树目录，避免 Desktop 初始目录与实际运行目录不一致。
`src/metadata-protocol.cjs` 定义有界会话元数据封装，`src/demand-protocol.cjs` 和 `src/remote-demand.cjs` 负责独立 viewer 租约、活动 CLI 控制面和目录广告。
`src/metadata-publisher.cjs` 保留旧目录写入协议的兼容测试，主流程不再用已计算快照发现远程需求。
`src/remote-reader.cjs` 在当前页面 GET 会话元数据，`src/remote-bridge.cjs` 负责主 frame 校验与 IPC 清理。
